# 사용성 리뷰 · 2026-10-03

현재 UI 미리보기와 실제 제어 코드의 동작을 함께 확인했습니다. 사용자 대상 설문/관찰 시험은 아니므로 최적의 디자인이라고 단정하지 않습니다.

| 사용자 작업 | 발견한 문제 | 반영한 변경 |
|---|---|---|
| 적용한 전력을 다시 바꾸기 | 입력과 적용이 잠기고 복원을 먼저 해야 함 | 앱이 소유한 설정은 편집 가능. 적용 시 이전 값을 검증·복원한 뒤 새 제한 적용. 이전 실행의 복원 의무는 계속 차단 |
| 전력 변경 여부 확인 | MSR·재조회 같은 내부 용어와 잘리는 긴 문장 | 변경 대기 / 적용 중과 적용한 W를 짧게 표시 |
| 커브를 바꿔 결과 보기 | 실행 중인 곡선과 편집값이 다르고 재적용 필요 | 편집 완료 후 0.5초 대기, 자동 복귀 응답 후 변경값 재적용. 드래그 중에는 대기 |
| 커브 시작/종료 구분 | 같은 ‘적용’ 버튼과 ‘자동’ 버튼 | 커브 시작 / 커브 제어 중 / 자동 냉각. 자동 냉각 상태에서 편집만으로 시작하지 않음 |
| 프리셋 보관하기 | ‘저장’이 하드웨어 적용인지 모호함 | ‘이름 저장’과 설명. 적용값 자동 저장과 이름 프리셋 저장을 구분 |
| 팬 속도 이해 | 요청한 임의 RPM과 삼성의 지원 단계가 다름 | 목표 실선·지원 단계 점선 설명을 짧게 표시. 실제 측정 RPM은 상단에 유지 |
| 0 RPM 해제 온도 | ‘정지 해제’가 좁은 행에서 잘림 | ‘팬 켜짐’으로 표시하고 툴팁에 자동 냉각 복귀 조건 설명 |
| 작은 화면에서 사용 | 696px 작업 공간에서 스크롤과 가로 잘림 | 그래프 높이를 축소. 해당 높이 편집기 검사를 추가 |
| 전력 적용 중 조작 | 숫자 입력을 비활성화해도 직접 그린 바는 움직일 수 있음 | 바가 원본 입력의 Enabled 상태를 따르도록 수정 |

검증: 오프라인 편집기에서 마우스/숫자/키보드 편집·프리셋 저장·활성 커브 재적용 예약과 비활성 편집의 분리, 작은 화면 경계 검사. 변경한 전력 재적용 및 커브의 실제 RPM 반영은 별도 실기 검증이 필요합니다.

남은 제약: 삼성 팬은 연속 RPM 제어가 아니라 정지와 검증된 회전 단계로 매핑됩니다. 동일 단계 안에서 값을 바꿔도 실제 RPM은 같을 수 있습니다. 회전 안정화에는 시간이 필요하며, 센서/열/전력 보호가 작동하면 자동 냉각으로 돌아갑니다. 최초 드라이버 설치와 정밀 보정은 메인 화면의 일상 조작과 다른 준비 절차입니다.
