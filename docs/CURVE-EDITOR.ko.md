# 팬 커브 편집과 사용자 프리셋

G-Helper의 공식 소스에서 커브의 X/Y 이동, 이웃 점 정렬, Shift 전체 이동과 저장/적용 동작을 확인하고 현재 하드웨어에 맞는 편집기로 구현했습니다. ASUS ACPI 명령이나 소스 코드를 이식한 것은 아닙니다.

참고: [G-Helper Fans.cs (확인한 커밋)](https://github.com/seerge/g-helper/blob/54c5bd00da82e20a0361228e5758f692b3b9560b/app/Fans.cs), [공식 수동 팬 제어 설명](https://github.com/seerge/g-helper/discussions/2272).

## 편집

- 점 8개를 좌우로 움직이면 온도, 위아래로 움직이면 요청 RPM이 바뀝니다.
- 그래프 아래 두 숫자 입력으로 선택점의 온도와 RPM을 직접 입력합니다.
- 온도 20~90°C, RPM 0~보정된 최대값을 편집합니다. 점은 순서를 유지하며 필요한 이웃 점도 함께 이동합니다.
- Shift+드래그/위아래 방향키는 전체 RPM 이동, Ctrl+Z는 직전 편집 취소입니다.
- 좌우 방향키는 선택점 온도, 위아래는 RPM, Ctrl+좌우는 점 선택입니다.
- 0 RPM과 회전 구간을 같은 커브에 넣을 수 있습니다. 0 RPM 지점을 포함하면 적용 시 5/10W 전력 제한이 함께 적용됩니다.
- 수정과 프리셋 선택만으로 실제 하드웨어를 변경하지 않습니다. **커브 적용**을 눌러 반영합니다.

## 저장

**이름으로 저장**에서 이름을 지정합니다. 목록의 `사용자 · 이름`을 고르면 온도·RPM·정지 해제온도가 다시 로드됩니다. 같은 이름은 확인 후 덮어쓰며 기본 프리셋은 덮어쓰거나 삭제할 수 없습니다. 사용자 프리셋만 삭제할 수 있습니다.

프리셋은 `%LOCALAPPDATA%\GalaxyHelper\fan-presets.json`에 저장합니다. 기존 파일은 원자적으로 교체하며 `.bak` 백업을 남깁니다. 저장과 삭제는 현재 하드웨어 설정을 변경하지 않습니다. 프리셋을 불러온 뒤 편집해도 원래 프리셋은 다시 저장하기 전까지 바뀌지 않습니다.

## 요청선과 실제 지원 속도

삼성에서 검증된 명령은 정지와 3개 회전 단계입니다. 임의의 PWM/RPM을 직접 쓰는 명령은 검증되지 않았습니다. 따라서 실선은 편집한 요청값, 점선은 보정값으로 계산한 지원 속도입니다. 양수 요청이 최저 회전 속도보다 낮으면 최저 회전 단계로 매핑합니다. 예를 들어 1000 RPM 점은 편집할 수 있지만 실제 1000 RPM 유지가 보장되는 것은 아닙니다. 현재 장비의 최저 회전 단계는 약3000 RPM입니다.

회전 구간은 기존80°C 보호, 정지 구간은 지정한 해제온도45~90°C와 커널의 전력/갱신 조건을 따릅니다. 보호로 자동 복귀하면 사용자가 다시 적용해야 합니다. 그래프를 편집했다고 이 보호가 해제되지는 않습니다.

## 테스트

`GalaxyHardware.exe self-test`에는 자유 X/Y 편집, 순서/범위, 혼합 커브 상승·하강 정책, 500개 임의 편집 회귀 검사가 포함됩니다.

`GalaxyHelper.exe --editor-self-test 결과.json`은 하드웨어를 열지 않는 별도 UI 검사입니다. 마우스 hit-test/drag, 숫자와 키보드 입력, 실행 취소, 실제 저장 버튼/이름 대화상자, 프리셋 파일 재로드와 삭제, 잘못된 파일 보존, 스크롤/잘림을 검사합니다. 사용자 파일을 바꾸지 않고 임시 저장소를 사용합니다.

## 트레이 패널

트레이 아이콘을 왼쪽 클릭하면 커서가 있는 화면의 우측 하단에서 패널이 열립니다. 작업표시줄에는 별도 창 버튼을 만들지 않습니다. 바깥 클릭, Esc, 접기 버튼으로 숨기며 제어는 계속됩니다. 고정 버튼을 켜면 바깥 클릭에도 열린 상태를 유지합니다. 오른쪽 클릭 메뉴의 ‘종료 및 설정 복원’은 기존과 동일합니다.

팬 커브와 사용자 프리셋은 항상 표시됩니다. 지속·단기 전력은 슬라이더로 5~80W 범위에서 0.5W 단위로 조절하며, 방향키로 미세 조절할 수 있습니다. 슬라이더 이동은 초안만 바꾸고 적용 버튼으로 하드웨어에 반영합니다.
