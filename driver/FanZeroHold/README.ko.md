# 지속 0 RPM 드라이버 0.5

`GALAXY_FAN_ZERO_HOLD` 빌드는 기존 버전1 요청을 그대로 지원하고 지속 정지용 버전2 요청만 추가합니다.

- 버전2 요청: 32바이트 기존 구조, Version=2, Mode=1(Start)/2(Renew), Owner≠0, Step 하위16비트=0, 상위16비트=해제온도45..90°C.
- 새 Ready 표식: FanZeroHoldReadyTime이 현재 부팅의 FanControlReadyTime과 같아야 합니다. 구 드라이버에는 버전2 요청을 보내지 않습니다.
- 반환 레코드64바이트의 마지막 DWORD는 적용된 해제온도이며 UI가 요청값과 대조합니다.
- 시작 온도 < 해제온도−5°C, 유지 온도 < 해제온도. 경계 도달 시 Auto.
- PL1/PL2 enable 비트와 한도 ≤5W/≤10W를 커널에서 확인합니다. MSR 읽기 실패나 조건 불일치면 Auto(StopReason11).
- 5초 임대, 3초 요청 유효기간, 소유자 검증, 센서 오류·절전·복원 기록 처리 유지. 30초 제한은 버전1 시험 명령에만 적용됩니다.
- 한 번의 정지 중에 한시/지속 정책이나 해제온도를 변경하지 못합니다. Auto 복귀 후 새 명시적 요청이 필요합니다.
- 펌웨어 열 보호를 끄거나 변경하지 않습니다.

2026-09-30: 네이티브46개, 기존22/14개, 앱32개 및 WDK 정적 분석/서명/INF 검사 통과. 로컬 설치는3010으로 재부팅 필요. 지속 정지 UI 실기60초 테스트는 대기 중입니다. 실제90°C까지 가열하는 시험은 수행하지 않았습니다.

`Prepare-Package.ps1`은 개발자의 WDK/인증서가 필요하며 설치하지 않습니다. `../Install-FanZeroHold.ps1`은 정확한 패키지 해시·인증서·기기 검증 후 설치만 합니다. 자동 재부팅하지 않습니다. `tools/Apply-ZeroHold.ps1`은 개발 장비용 배포 절차이며 이미 새 드라이버가 활성화된 경우에만 실제60초 UI 시험을 실행합니다.
