# 최신 상태: 사용자 팬 쓰기 승인 완료 / oem304 설치 / 재부팅 대기

2026-09-27 사용자 승인으로 후보를 설치했습니다. Windows 반환 3010으로 아직 새 코드 적용 전입니다. 실제 팬 시험은 재부팅 후 기존 승인 범위에서 진행합니다. 아래는 설치 전 준비 기록입니다.

# 팬 2단계 / 15초 시험 후보 — 미설치·미실행

이 빌드는 RPM 상한 제어가 아니라 자체 ACPI 경로의 쓰기와 자동 복귀를 검증하기 위한 제한된 시험입니다. 현재 설치된 0.1.3 드라이버는 읽기 전용입니다. **사용자의 별도 팬 쓰기 승인을 받기 전 Install-FanTrial.ps1 또는 Request-Trial.ps1을 실행하지 않습니다.**

## 준비된 동작

- 새로운 관리자 레지스트리 요청 번호가 있을 때만 실행. 부팅 시 남아 있던 시험 요청은 무시합니다.
- 동일 모델/BIOS/SAM0430, 지원 서명, 최대 단계 3 또는 6 확인.
- CPU 패키지 온도 센서가 유효하고 75°C 미만일 때만 시작.
- 삼성 공식 진단에서 확인된 `43 58 2C 00 00 02 ...`로 **2단계만** 적용.
- 약 15초 동안 RPM과 온도를 기록하고 `43 58 2C 00 00 80 ...`로 자동 제어 복귀.
- 80°C 도달, 센서/RPM 읽기 실패, D0 전원 이탈 요청 시 일찍 복귀.
- 커널 콜백이 시간 제한과 복귀를 담당하므로 사용자 앱 종료와 독립적입니다. 드라이버 정지/절전은 콜백을 기다립니다.
- 설정 요청이 실패해도 부분 적용 가능성을 고려해 자동 복귀를 요청합니다. 복귀 실패는 성공으로 표시하지 않으며 활성 상태에서 2초마다 자동 복귀를 재시도합니다.
- 펌웨어가 호출을 완료하지 않거나 OS가 비정상 종료되는 상황까지 소프트웨어 복귀를 보장하지는 않습니다.
- 임의 RPM/팬 단계/시간/주소 입력과 팬 정지 명령은 없습니다. 성능 모드·전력 제한도 바꾸지 않습니다.

## 준비 및 검증 결과

`Prepare-Package.ps1`은 별도 후보만 빌드·서명하며 설치/실행하지 않습니다. 0.2.0.0 후보는 Release 정적 분석 경고/오류 0, API Validator, INF/CAT, SYS 서명/카탈로그 멤버 검증을 통과했습니다. 기본 읽기 전용 빌드에 시험용 명령 문자열이 포함되지 않는 것도 검사했습니다. 실제 팬 쓰기·자동 복귀·절전 경합은 미검증입니다.

- 후보: `artifacts/driver/package-FanTrial`
- 설치: `driver/Install-FanTrial.ps1` (파일 해시 고정, 승인 후에만 실행)
- 새 드라이버 적용 후 시험: `driver/FanStepTrial/Request-Trial.ps1`
- 측정 기록: `artifacts/fan-step-trial-result.json`

드라이버 교체에는 재부팅이 다시 필요할 수 있습니다. 설치 자체는 팬 시험을 시작하지 않습니다. 이전 연구용 oem303/302/297/291.inf와 삼성 기본 oem145.inf를 구분해야 합니다. 후보는 아직 게시된 oem 이름이 없습니다.

출력 State: 1 준비, 2 적용, 3 복귀 중, 4 자동 복귀 응답 성공, 5 복귀 실패, 6 적용 전 거부. StopReason: 1 시간 만료, 2 전원 전환, 3 온도/센서, 4 RPM 읽기, 5 설정 호출 실패, 6 사전 조건. 성공 응답만으로 RPM 상한이 검증됐다고 판단하지 않고, 실제 RPM 변화와 복귀 후 새 읽기를 대조해야 합니다.
