# 자동 팬 설정 앱 업데이트

이 묶음은 GalaxyHelper.exe, 진단 EXE 및 PawnIO 모듈을 포함합니다.
이미 설치된 공식 PawnIO와 GalaxyHelper 모델 전용 팬 드라이버를 사용합니다.
드라이버·인증서를 포함하는 전체 설치 EXE는 개발 장비에서
`packaging/Build-SingleExe.ps1`로 별도로 패키징해야 합니다.

1. 기존 앱 트레이에서 **종료 및 설정 복원**을 선택합니다.
2. ZIP을 파일 쓰기 가능한 새 폴더에 풀고 `GalaxyHelper.exe`를 실행합니다.
3. 관리자 권한 요청을 허용합니다. 보정 기록이 없거나 만료됐으면
   자동 설정 창이 열리고 약 7~9분 동안 보정·검증이 진행됩니다.
4. 성공하면 커브가 자동 활성화됩니다. 취소·실패 시 결과를 확인하고
   **팬 설정**에서 다시 시도할 수 있습니다.

검증 중에는 부하 작업을 닫고 삼성 성능 모드를 유지하세요.
기존 전력 복원 기록이 있으면 메인 화면의 **원래대로**를 먼저 누르세요.
실행 결과는 `%LOCALAPPDATA%\GalaxyHelper\diagnostics`에 저장됩니다.

지원 모델: Galaxy Book6 Pro - PAMB / Core Ultra X7 358H
지원 BIOS: PAMB.1.5.74.371
오프라인 CI는 실제 기기의 팬·전력·열 안정성을 검증하지 않습니다.
