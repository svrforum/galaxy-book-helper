# 단일 EXE 및 ZIP 앱 업데이트

릴리즈의 단일 GalaxyHelper EXE는 앱·진단 도구·PawnIO 모듈을 내장합니다.
EXE 하나를 실행하면 필요한 파일을 자동으로 준비하며, 수동 압축 해제가 필요 없습니다.
ZIP 배포판도 함께 제공합니다.

기존에 설치된 공식 PawnIO와 GalaxyHelper 모델 전용 팬 드라이버를 사용합니다.
처음 사용하는 분은 릴리즈의 Setup EXE와 시작 안내를 받으세요.
Setup은 시험용 팬 드라이버·공개 인증서를 포함하며 공식 PawnIO 설치를 안내합니다.

1. 기존 앱 트레이에서 **종료 및 설정 복원**을 선택합니다.
2. 새 단일 EXE를 실행하고 관리자 권한 요청을 허용합니다.
3. 기본 시작에서는 짧은 드라이버·센서 검사를 수행합니다. 새 RPM 조회는 최대 15초입니다.
4. 유효한 보정 기록이 있으면 커브를 바로 사용합니다. 기록이 없거나 만료됐으면
   **정밀 보정**을 선택해야 정확한 RPM 커브를 사용할 수 있습니다.

정밀 보정은 약 7~9분이며, 기본 시작 시 자동으로 실행하지 않습니다.
진행 중에는 부하 작업을 닫고 삼성 성능 모드를 유지하세요.
기존 전력 복원 기록이 있으면 메인 화면의 **원래대로**를 먼저 누르세요.
실행 결과는 `%LOCALAPPDATA%\GalaxyHelper\diagnostics`에 저장됩니다.

성공적으로 적용한 전력·커브는 앱 재실행 시 다시 적용합니다. Windows 로그인 시 자동 실행하려면 트레이 우클릭의 시작 체크를 켜세요. 커브 제어 중에는 편집을 마친 뒤 변경값을 자동 재적용합니다.

지원 모델: Galaxy Book6 Pro - PAMB / Core Ultra X7 358H
지원 BIOS: PAMB.1.5.74.371
오프라인 CI는 실제 기기의 팬·전력·열 안정성을 검증하지 않습니다.
