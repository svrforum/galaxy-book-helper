# Galaxy Book Helper v0.1.1-experimental

**EXE 파일 하나로 실행**할 수 있으며, 기본 실행에서 오래 걸리는 RPM 보정을 자동으로 시작하지 않습니다.

## 다운로드

아래 Assets에서 **GalaxyHelper-v0.1.1-experimental-windows-x64.exe** 하나를 받으세요. 앱·진단 도구·PawnIO 모듈이 내장되어 있어 수동 압축 해제가 필요 없습니다. 기존 앱에서 **종료 및 설정 복원** 후 새 EXE를 실행하고 관리자 권한 요청을 허용하세요.

ZIP 배포판도 선택할 수 있지만 단일 EXE를 실행하려면 ZIP을 함께 받을 필요가 없습니다.

## 빠른 시작

- 시작할 때 드라이버 준비 상태와 새 팬 RPM만 확인합니다. 전력 제한 변경이나 단계별 팬 제어를 수행하지 않습니다.
- 새 RPM 조회는 **최대 15초**로 제한합니다. UAC, 파일 준비, 드라이버 초기화까지 포함한 전체 실행 시간을 보장하는 값은 아닙니다.
- 유효한 보정 기록이 있으면 그대로 사용합니다.
- 기록이 없거나 만료됐으면 정확한 RPM 커브는 **정밀 보정** 후 사용할 수 있습니다. 짧은 센서 검사를 정밀 보정으로 표시하지 않습니다.

정밀 보정은 선택 실행이며 약 7~9분입니다. 팬이 각 단계에서 안정화된 후 측정하고 목표 RPM 유지·자동 복귀를 확인합니다. 기본 시작 시 실행하지 않습니다. 보정 중에는 취소할 수 있으며, 팬과 전력 복원 후 결과를 표시합니다.

## 설치 범위

단일 EXE는 **기존에 설치된 공식 PawnIO와 모델 전용 팬 드라이버**를 사용합니다. 드라이버 설치 파일·테스트 인증서는 내장하지 않았습니다. 드라이버가 없는 새 PC에서는 먼저 [드라이버 설치 안내](https://github.com/svrforum/galaxy-book-helper/blob/main/driver/README.ko.md)를 확인하세요. 드라이버까지 포함하는 전체 설치형에는 별도의 서명된 드라이버 패키지가 필요합니다.

지원 대상: Windows x64 / Galaxy Book6 Pro - PAMB / Core Ultra X7 358H / BIOS PAMB.1.5.74.371.

## 검증

Windows 빌드, 오프라인 테스트 45개, 편집·프리셋 UI 테스트 14개, 설정·취소·오류 UI 테스트 9개, 네이티브 정책 검사 82개를 실행합니다. 단일 EXE의 내장 파일 검증 및 모듈 누락·앱 변조 거부 테스트도 실행하며, 모두 통과한 파일만 게시합니다.

실제 기기의 시작 시간, 정밀 보정·절전·장시간 열 안정성은 추가 확인이 필요합니다. SHA-256은 함께 첨부한 **SHA256SUMS.txt**에서 확인할 수 있습니다.
