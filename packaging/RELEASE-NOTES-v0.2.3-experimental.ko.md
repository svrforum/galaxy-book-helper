# Galaxy Book Helper v0.2.3-experimental

**처음 사용하는 분은 `GalaxyHelper-v0.2.3-experimental-Setup.exe` 하나를 받으세요.** 관리자 실행과 필요한 구성 요소 설치를 안내합니다. 자세한 순서는 함께 올린 시작 안내 `FIRST-START.ko.md`에 있습니다.

대상: **Galaxy Book6 Pro - PAMB / Core Ultra X7 358H / BIOS PAMB.1.5.74.371**, Windows 11 x64. 다른 모델·BIOS는 지원하지 않습니다.

- Setup EXE: 앱·모듈·시험용 팬 드라이버·공개 테스트 인증서 포함. 필요한 경우 공식 PawnIO 2.2.0을 다운로드하며 고정 해시와 서명을 확인합니다.
- App EXE / ZIP: 이미 필요한 드라이버를 설치한 사용자를 위한 앱 업데이트입니다. 팬 드라이버 설치 기능은 없습니다.
- SHA256SUMS.txt: 다운로드 파일 무결성 확인용입니다. 앱은 미서명입니다.

팬 커브·0 RPM용 자체 드라이버는 Microsoft 정식 서명이 아닙니다. **개발·시험 참여자 전용**이며 Secure Boot 해제와 현재 부팅의 TESTSIGNING 활성화가 필요합니다. 설치 프로그램은 보안·부팅 설정을 자동 변경하지 않습니다. 조건이 맞지 않거나 팬 설치를 거절하면 팬 제어 없이 앱을 실행합니다. Secure Boot 환경의 기본 기능은 새 PC 실기 검증 전입니다.

설치 오류 수정: v0.2.0의 Windows PowerShell 5.1 UTF-8 파일명 해석 오류를 수정했습니다. EXE에서 실제 Windows PowerShell과 Start.ps1을 실행하는 읽기 전용 사전 검사, BOM 유무별 한글 경로 회귀 검사를 추가했습니다.

추가 기능: 배터리 잔량, 배터리 사용 시 PC 전체 방전 전력, 최근 1분 평균 기준 예상 남은 시간을 표시합니다. 충전 중에는 충전 중으로 표시합니다. 콘센트 입력 전력을 측정하는 기능은 아닙니다. 조회는 5초 간격이며 별도 드라이버가 필요 없습니다. 이 장비에서는 충전 상태·잔량 조회를 확인했고 방전 상태 실측은 아직 수행하지 않았습니다.

이번 버전:
- 작은 트레이 패널, 밝기·동일 비율 해상도·60/120Hz 선택
- 작은 작업 영역에서는 그래프 높이를 줄여 버튼을 화면 안에 유지
- 배터리 정보는 상단의 작은 상태 줄에 배치
- 사용성 리뷰: 앱이 적용한 전력값을 다시 편집·적용, 명확한 커브 시작/자동 냉각/이름 저장 표시
- 성공적으로 적용한 전력·팬 커브를 앱 재실행 시 자동 복원
- 트레이 체크로 Windows 로그인 시 자동 실행·마지막 적용값 복원
- 전력·팬 사용자 프리셋, 직접 편집하는 커브
- **커브 제어 중 편집을 마치면 변경값 자동 재적용**; 자동 냉각 중에는 적용 버튼으로 시작

실제 팬은 검증된 0/회전 단계로 동작합니다. 요청 RPM이 바뀌어도 같은 지원 단계에서는 실제 속도가 같을 수 있습니다. 정밀 보정은 최초/만료 시 약 7~9분입니다. 장시간 무팬·90°C 도달 시험 및 새 Windows 최초 설치 전체 경로는 미검증입니다. 재실행 팬 커브 수정본의 실기 재검증도 아직 완료하지 않았습니다.

업데이트: 기존 앱 트레이 → **종료 및 설정 복원** → 새 EXE 실행. 설정은 사용자 폴더에 유지합니다. 설치·제거·시험 환경 준비는 시작 안내를 확인하세요.

자동 업데이트: 기본 활성화. 실행 후 및 6시간마다 공개 GitHub 릴리즈를 확인하고 앱 EXE를 다운로드합니다. GitHub SHA256·파일 크기·내장 패키지를 검증한 뒤 패널이 닫혀 있고 제어 작업이 끝나면 전력·팬을 정상 복원하고 새 앱으로 재실행합니다. 저장된 설정과 기존 드라이버는 유지합니다. 트레이 메뉴에서 자동 업데이트를 끄거나 즉시 확인/설치할 수 있습니다. 다운로드 실패 또는 복원 실패 시 현재 앱을 유지합니다. 이 버전부터 지원하므로 기존 버전에서는 한 번 수동 업데이트가 필요합니다.
