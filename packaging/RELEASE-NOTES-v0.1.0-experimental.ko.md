# Galaxy Book Helper v0.1.0-experimental

EXE 첫 실행 자동 팬 보정과 검증을 추가한 Windows x64 앱 업데이트입니다.

## 다운로드와 실행

아래 Assets에서 **GalaxyHelper-v0.1.0-experimental-windows-x64.zip**을 받으세요.

1. 기존 앱 트레이에서 **종료 및 설정 복원**을 선택합니다.
2. ZIP을 새 폴더에 모두 풀고 **GalaxyHelper.exe**를 실행합니다. `modules` 폴더도 함께 있어야 합니다.
3. 관리자 권한 요청을 허용합니다.
4. 보정 기록이 없거나 만료됐다면 **팬 자동 설정**이 자동 시작됩니다. 유효한 기록이 있으면 바로 정상 화면을 엽니다.

기존에 설치된 공식 **PawnIO**와 이 프로젝트의 모델 전용 팬 드라이버를 사용합니다. 이 ZIP에는 드라이버 설치 파일이나 테스트 인증서가 포함되지 않습니다. 드라이버가 아직 없다면 [드라이버 설치 안내](https://github.com/svrforum/galaxy-book-helper/blob/main/driver/README.ko.md)를 먼저 확인하세요.

## 변경 사항

- 앱 내부에서 단계별 팬 RPM 측정, 갱신 중단 시 자동 냉각 복귀, RPM 목표 유지 검증을 진행합니다. 별도 PowerShell 명령이 필요하지 않습니다.
- 진행 상태와 취소 버튼을 제공합니다. 완료·취소·실패 시 팬 자동 복귀와 원래 전력 복원을 시도하며, 검증과 복원이 성공한 뒤에만 보정을 승인합니다.
- 성공하면 앱 재실행 없이 팬 커브가 활성화됩니다. **팬 설정** 버튼과 트레이 메뉴에서 재보정할 수 있습니다.
- 작은 화면에서 컨트롤이 잘리는 문제를 수정했습니다. 더 작은 작업 영역에서는 스크롤로 모든 버튼에 접근할 수 있습니다.
- 진단 기록을 `%LOCALAPPDATA%\GalaxyHelper\diagnostics`에 저장합니다.

## 자동 보정 안내

약 **7~9분** 동안 전력을 임시로 **10/10W 이하**로 낮추고 팬을 단계별로 회전시킵니다. 부하 작업을 닫고 삼성 성능 모드를 유지하세요. 진행 창에서 취소할 수 있습니다.

이전 전력 복원 기록이 남아 있으면 자동 보정을 보류합니다. 메인 화면의 **원래대로**를 누른 뒤 **팬 설정**으로 다시 시작하세요. 드라이버 설치 직후에는 Windows 재시작 및 준비 시간이 필요할 수 있습니다.

## 지원 및 검증 범위

- Windows x64 / .NET Framework 4.x
- **Galaxy Book6 Pro - PAMB / Core Ultra X7 358H / BIOS PAMB.1.5.74.371** 전용
- Windows 빌드, 앱 오프라인 테스트 41개, 편집·프리셋 UI 테스트 14개, 자동 설정·취소·오류 UI 테스트 9개, 네이티브 정책 검사 82개 통과 후 게시

이번 자동 설정 흐름은 오프라인·UI 테스트를 통과했습니다. 실제 기기의 자동 보정, 절전 및 장시간 열 안정성은 추가 확인이 필요합니다. 기존 0 RPM 실기 검증은 60초 시험이며, 장시간 무팬 사용을 검증한 것은 아닙니다.

ZIP의 SHA-256은 함께 첨부한 **SHA256SUMS.txt**에서 확인할 수 있습니다.
